
LBH SURYA NTT – Shorinji Kempo
LBH SURYA NTT adalah dojo Shorinji Kempo di Kupang yang menjadi pusat latihan, pengembangan karakter, dan wadah kebersamaan. Website ini berfungsi sebagai galeri digital, dokumentasi kegiatan, dan media informasi bagi anggota maupun masyarakat umum.

Struktur Proyek
html/ — halaman utama seperti index.html, explore_dojo.html

css/ — styling modular untuk tiap section (tentang dojo, program latihan, galeri, kontak)

js/ — interaksi ringan dan animasi scroll (navbar sticky, slideshow, validasi form)

assets/image/ — foto kegiatan, logo dojo, dokumentasi kejuaraan

Fitur Utama
Scroll animation dan cinematic text untuk pengalaman interaktif

Layout responsif agar nyaman di desktop maupun mobile

Galeri kegiatan dengan slideshow otomatis

Kontak interaktif dengan card layout dan Google Maps embed

Branding visual khas Shorinji Kempo LBH SURYA NTT
